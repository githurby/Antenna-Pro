Antenna Pro Engineering

From preliminary geometry to a measured 50-ohm feed system: an illustrated guide to building, matching, checking, and documenting antennas with the native Windows application.

Windows 10/11Code::Blocks + MinGW-w64C++17Win32 + OpenGL

1. What the program does

Antenna engineering

  • 11 antenna topologies
  • 1–5 element Yagi, Delta Loop, and Cubical Quad arrays
  • Initial construction dimensions
  • Estimated gain, F/B, and bandwidth

Feed-system engineering

  • Measured or estimated R+jX
  • Fixed 50-ohm target
  • L network, BALUN, UNUN, gamma, or direct feed
  • Voltage/current and mismatch figures
Scope: this is a preliminary engineering and matching tool, not a full-wave electromagnetic solver. A physical antenna must be verified with a VNA in its installed environment.

2. Install and build

Requirements

  • Windows 10 or 11, preferably 64-bit.
  • Code::Blocks with a MinGW-w64 GCC toolchain.
  • OpenGL support supplied by Windows and the display driver.
  1. Extract the complete project to a normal writable folder, for example C:\Projects\AntennaPro.
  2. Open AntennaPro.cbp in Code::Blocks.
  3. If requested, select GNU GCC Compiler.
  4. Select the Release target for normal use.
  5. Run Build → Clean, then Build → Rebuild.
  6. Run bin\Release\AntennaPro.exe.
Command-line alternative: mingw32-make -f Makefile.win clean mingw32-make -f Makefile.win
The project intentionally links with -municode because the entry point is wWinMain. Do not remove it.

4. Recommended design workflow

  1. Define requirements: frequency, bandwidth, polarization, gain, direction, power, and available space.
  2. Calculate an initial geometry: leave Measured R at zero.
  3. Build with adjustment margin: allow approximately 1–3% extra length where trimming is possible.
  4. Install the real system: include the intended boom, mast, insulators, coax, and ground arrangement.
  5. Measure unmatched R+jX: calibrate the VNA at the feed reference plane.
  6. Recalculate: enter measured R and X, then calculate again.
  7. Open the matching diagram: build the displayed network with short RF connections.
  8. Tune iteratively: use low power and repeat VNA measurements.
  9. Validate: check common-mode current, temperature, bandwidth, pattern, structure, lightning protection, and legal compliance.

5. How automatic 50-ohm matching works

Direct + 1:1 device

Used when the antenna is already close to 50+j0 Ω. A current balun serves balanced antennas; a choke serves unbalanced radiators. A 1:1 device does not transform impedance.

Low-pass L network

Used for a non-50-ohm resistance. The program cancels measured reactance and calculates series and shunt components.

Q = √(Rhigh/Rlow − 1) Xs = Q · Rlow Xp = Rhigh/Q

BALUN / UNUN transformer

Used for loops, quads, and end-fed systems. Ideal turns ratio:

Nantenna/N50 = √(Rantenna/50)

Gamma match

Used for a low-impedance driven element in a multi-element Yagi. Geometry raises resistance and a series component cancels reactance.

The displayed 50+j0 Ω is an ideal center-frequency prediction. Component parasitics and installation effects require physical adjustment.

6. Gamma-match construction

  • The coax shield connects to the driven element.
  • The center conductor reaches the gamma rod through the calculated series component.
  • The sliding shorting strap connects the far end of the gamma rod to the driven element.
  • Adjust rod/strap position mainly for resistance; adjust the series capacitor mainly for reactance. Repeat.
  • Install a separate 1:1 common-mode choke on the coax.
Never feed a director or reflector. They are parasitic elements. Only the driven element is electrically connected to the feed system.

7. BALUN and UNUN connection

For a balanced loop, dipole, or quad, connect the two balanced terminals across the driven element/feed gap. For an end-fed system, the high-impedance UNUN terminal goes to the radiator and the return goes to the designed counterpoise/RF return. Test the transformer first with a suitable non-inductive resistor.

9. Refining the design with a VNA

  1. Disconnect the transmitter and use a safe, receive-level VNA only.
  2. Perform SOLT/OSL calibration at the end of the fixture or cable that defines the matching plane.
  3. Measure the antenna without the proposed matching network.
  4. Read the complex impedance at the target frequency: R and X.
  5. Enter R and X into Antenna Pro and recalculate.
  6. Build the network and measure again at the same plane.
  7. Adjust until R is near 50 and X is near zero, while checking the full required bandwidth.
A remote feed cable rotates impedance around the Smith chart. Calibration at the wrong plane can produce the wrong matching components.

10. Worked example: five-element Yagi

Input27.205 MHz, 20 mm driven-element tube, 5 elements, 100 W
Estimated native feedApproximately 28+j0 Ω in the analytical model
Automatic methodGamma match plus a 1:1 coax choke
Program outputGamma-rod diameter, center spacing, rod length, stub Z0, step-up factor, and series capacitor
  1. Calculate once with measured R set to zero.
  2. Build and install the Yagi with an adjustable gamma rod and shorting strap.
  3. Measure the unmatched driven-element impedance if the fixture permits.
  4. Enter measured R+jX and recalculate.
  5. Open the matching diagram and use its revised dimensions.
  6. Adjust the strap for resistance and capacitor for zero reactance.
  7. Add the choke and verify that moving the coax does not significantly change SWR.

13. Safety and engineering limits

RF and electrical safety: matching networks and end-fed antennas can develop dangerous voltage. Never touch, tune, or modify an energized antenna. Keep the complete structure far from overhead electrical conductors.
  • Use legal frequencies and power.
  • Evaluate RF exposure.
  • Provide lightning protection.
  • Bond and ground correctly.
  • Perform wind and ice calculations.
  • Use rated insulators and hardware.
  • Check capacitor voltage.
  • Check core temperature and saturation.
  • Weatherproof without trapping water.
  • Document every final measurement.

Final acceptance criteria

  • VNA calibration and reference plane documented.
  • Final R+jX, SWR, and bandwidth recorded.
  • Common-mode current controlled.
  • No excessive heating or arcing at rated power.
  • Mechanical and lightning design independently approved.
  • Radiated behavior validated—not inferred only from SWR.
